# Exercise 1-1 - Ch01GuitarShop

Put your **existing Ch01GuitarShop** project files in this folder.

That is: unzip your `Ch01GuitarShop.zip`, then copy the inner `GuitarShop/`
folder (the one that contains `GuitarShop.csproj`, `Program.cs`, `Controllers/`,
`Models/`, `Views/`, `wwwroot/`, etc.) into **this directory**.

When you are done, this directory should contain:

```
Exercise1-1_Ch01GuitarShop/
└── GuitarShop/
    ├── GuitarShop.csproj
    ├── Program.cs
    ├── appsettings.json
    ├── Controllers/
    ├── Models/
    ├── Views/
    └── wwwroot/
```

You already ran this project in Visual Studio for Exercise 1-1, so nothing
else needs to change here - just drop the files in and commit them to the
`Week 1` branch along with the other two exercises.
